# Spec: seeded random streams

This is the exact algorithm behind `Rng` in `packages/core/src/rng.ts`. A port to another language (C++ for Unreal, C# for anything else) that follows it produces the same numbers. The golden vectors at the end are how to check a port.

[`rng_oracle.py`](rng_oracle.py) is an independent implementation of this page in Python. CI runs it and compares every golden case with `@eb/core` (`packages/core/src/rng.oracle.test.ts`).

All arithmetic is on 32-bit words modulo 2³². Shifts are logical (unsigned), and multiplication keeps the low 32 bits (JavaScript's `Math.imul`). No floating point is involved, which is why every JavaScript engine agrees.

## Hashing a seed: FNV-1a, 32-bit, over UTF-8

```
h = 0x811C9DC5
for each byte of the string encoded as UTF-8:
    h = (h XOR byte) * 0x01000193   (mod 2³²)
```

- The input is the UTF-8 bytes, not UTF-16 code units, so the published FNV test vectors apply and every language agrees.
- A lone surrogate encodes as U+FFFD (`EF BF BD`), as the browser's `TextEncoder` does.

`hashParts(a, b, …)` is FNV-1a of the parts joined by U+001F (unit separator). Numbers are written in decimal.

## Expanding a seed: splitmix32

```
a = fnv1a32(seed)
next():
    a = a + 0x9E3779B9
    t = a XOR (a >> 16)
    t = t * 0x21F0AAAD
    t = t XOR (t >> 15)
    t = t * 0x735A2D97
    return t XOR (t >> 15)
```

## The generator: sfc32

The state is four words, a, b, c and d.

- **Creating a stream from a seed string:**
  1. Set a, b, c and d to splitmix32's first four outputs, in that order.
  2. Draw and discard 12 outputs (warm-up).
- **Each draw:**

```
t = a + b + d
d = d + 1
a = b XOR (b >> 9)
b = c + (c << 3)
c = (c << 21) OR (c >> 11)        rotate left by 21
c = c + t
return t
```

## Streams and state

- **Forking.** `fork(label)` creates a new stream from the seed `seed + U+001F + label`, with numbers written in decimal. A fork depends only on the parent's seed and the label, never on how many numbers the parent has drawn.
- **Saving.** `toState()` returns `{ seed, s: [a, b, c, d] }` as unsigned integers.
- **Resuming.** `fromState()` resumes from exactly that point. Games keep this in their state, so reloading a save never rerolls.

## Helpers

| Helper | Definition |
| --- | --- |
| `int(min, max)` | span = max − min + 1 (at most 2³²); limit = 2³² − (2³² mod span). Draw until x < limit, then return min + (x mod span). Rejection removes modulo bias. |
| `chance(num, den)` | `int(1, den) <= num`. Integer odds: `chance(70, 100)` is 70%. |
| `pick(list)` | `list[int(0, length − 1)]` |
| `weightedIndex(w)` | Integer weights ≥ 0, total between 1 and 2³². roll = `int(0, total − 1)`; walk the weights subtracting each, and return the first index where roll goes below 0. A zero weight is never chosen. |
| `shuffle(list)` | Fisher–Yates on a copy: for i from length − 1 down to 1, j = `int(0, i)`, swap i and j. |

Bad input throws instead of guessing. That includes an empty or reversed range, odds outside 0…den, negative or fractional weights, an empty list, and a malformed state.

## Golden vectors

Unsigned decimal. Generated by `rng_oracle.py` and frozen in `packages/core/src/rng.test.ts`. Changing any of them changes every seeded game, so it needs a decision, not an update.

| Case | Expected |
| --- | --- |
| `fnv1a32("")` | 2166136261 |
| `fnv1a32("a")` | 3826002220 |
| `fnv1a32("foobar")` | 3214735720 |
| `fnv1a32("engine-builder")` | 17088301 |
| `fnv1a32("Landnám")` | 860136389 |
| `fnv1a32("🙂")` | 1470331467 |
| `hashParts("run-7", 3, 12)` | 893192154 |
| `create("engine-builder")`, 8 draws | 1378790326, 99929701, 3719599711, 3668007137, 2638831411, 4283105152, 3659860869, 927470604 |
| `create("engine-builder").fork("loot")`, 4 draws | 3339932023, 4083315149, 1132011579, 604863715 |
| `create("engine-builder").fork(7)`, 2 draws | 118457561, 2351127793 |
| `create("engine-builder")` state after 3 draws | [1404016108, 254128723, 2904986454, 2009862306] |
| `create("dice").int(1, 6)` × 12 | 1, 4, 5, 6, 1, 2, 2, 1, 5, 4, 1, 5 |
| `create("wide").int(0, 3221225471)` × 8 | 132213907, 1586911512, 2090067538, 116268688, 1124933079, 589598981, 2311357304, 275667628 |
| `create("odds").chance(70, 100)` × 10 | T, F, T, F, T, T, T, T, F, T |
| `create("deck").shuffle([0…9])` | 0, 3, 5, 7, 2, 9, 4, 6, 8, 1 |
| `create("weights").weightedIndex([5, 0, 3, 2])` × 10 | 3, 0, 2, 3, 0, 0, 2, 0, 2, 0 |

The `wide` case is there on purpose. A quarter of raw draws fall past the limit at that span, and its 8 values took 11 raw draws. So a port that skips rejection fails this case, even though it would pass the dice case.

## Provenance

- The generator, its seeding and the fork scheme come from chooser-of-the-dead's engine (`packages/engine/src/rng/rng.ts`).
- `toState` / `fromState` and `weightedIndex` were added for the engine (decision D17).
- The splitmix32 variant (a golden-ratio increment, then a two-multiply mix with 0x21F0AAAD and 0x735A2D97) is the one chooser-of-the-dead uses.
- sfc32 comes from PractRand.
